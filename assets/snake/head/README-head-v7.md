# 蛋挞蛇头 v7：颈部为头高的80%

根据用户 `蛇头.png` 草图制作。保留朝左张嘴、上下折角状嘴缘、小圆眼与短眉线，采用现有柔金棕酥皮、奶黄内馅和焦糖烤斑。最终使用均匀固有色，无预制投影、高光、渐变或立体倒角。

## 文件

- `tart-snake-head-left-v7.png`：默认朝左，1120 × 880，透明 PNG。
- `tart-snake-head-right-v7.png`：朝右，1120 × 880，透明 PNG。
- `tart-snake-head-up-v7.png`、`down`：朝上／朝下，880 × 1120，透明 PNG。四方向由同一张定稿按90度旋转导出。
- `tart-snake-head-{left,up,right,down}-{128,256,512}-v7.png`：四方向的三种正方形透明精灵尺寸，按比例缩放，未拉伸。
- `source/tart-snake-head-left-v7.svg`：可编辑矢量主文件，画布280 × 220。
- `head-assets-v7.json`：四方向尺寸、旋转中心、颈部连接点与身体比例。
- `source/user-sketch-v1.png`、`head-generated-v1.png` 至 `v5`：用户草图与内置 image_gen 制作稿，原样保留。v6 主文件和 PNG 也保留用于对照，以 v7 为当前定稿。

## 比例与接入

以 SVG 单位计，头部实际轮廓高160，颈部厚128，比例128 / 160 = 0.8。默认PNG放大4倍，实际头高640像素、颈部512像素，栅格测量也恰为80%。颈部与运行时身体保持等宽，因此显示头高为身体宽度的1.25倍。

颈部开口在 `(262,108)`，默认 PNG 中为 `(1048,432)`。它是无封口描边的开放切面。颈部截面与身体采用相同比例：外酥皮每侧12、内沿每侧10、内馅84，对应总宽128。面部嘴缘的酥皮适度收细，过渡到颈部标准厚度，保留完整内馅与清楚的折角轮廓。

默认 PNG 的旋转中心为 `(740,432)`。运行时缩放系数为 `身体显示宽度 / 512`；不要按整张图片的宽度去等比替代身体宽度。其他朝向的锚点已写在 JSON，使用对应图像与锚点即可。

身体在下、头部在上，两者在颈部重叠约1-2个显示像素，处理抗锯齿边缘。移除旧的头部占位端帽。头与身体复用同一位置、方向和穿屏副本，边界只裁切，不额外封口。替换素材不自动修改碰撞范围。
