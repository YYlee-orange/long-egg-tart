# 超长蛋挞素材交付 v2

日期：2026-10-16。当前定稿采用低饱和浅木桌、柔金棕酥皮、奶黄色内馅和克制的焦糖纹理。无棋盘、网格、烘焙道具。食物和角色均为固有色平涂，无投影、接触阴影、固定高光、渐变塑形、倒角或环境遮蔽。

- 食物：`food/custard-carton-flat-v5.png`，512 × 640，透明 PNG。简化纸盒折顶、旋盖与单个液滴。配套 `custard-carton-48-v5.png`、`64`、`128`、`256` 为正方形透明精灵，适合直接载入。可编辑定稿：`food/source/custard-carton-flat-v5.svg`。
- 贴花图集：`snake/decals-atlas-flat-v5.png`，1024 × 1024，RGBA；4 × 4 排列，单格 256 × 256，前 12 格为烤斑，后 4 格为酥皮细纹。图片不含文字、编号或网格。坐标、透明边距、固有色、枢轴与有效内容框位于 `snake/decals-atlas-flat-v5.json`。
- 独立贴花：`snake/decals/bake-01-v5.png` 至 `bake-12-v5.png`；`pastry-01-v5.png` 至 `pastry-04-v5.png`。每张均为 256 × 256 透明 PNG，另附同名 SVG。
- 完整机器清单：`asset-manifest-v2.json`。其 `primaryAssets` 为当前可接入的 23 张 PNG；旧稿与源图不应误当最终游戏纹理。

原始位图使用内置 image_gen 生成并修订，提示词保存在 `../previews/art-assets/image-prompts-v1-v3.md`。生成原图仍有极轻微面内色差，所以保留原图作为制作记录，并将定稿制作成干净、可编辑的平涂矢量主文件，再导出 PNG。贴花沿用生成轮廓，纸盒按生成方向制作简化平涂主文件。所有旧稿、v4 和首轮预览均已保留；v5 主要增强酥皮细纹的小尺寸可读性，纸盒与 v4 相同。

## 蛇身统一结构

身体不提供重复拼接的完整小蛋挞块。使用一条连续中心路径，先后绘制外酥皮、内沿、内馅三层。整条路径只绘制一次每一层，贴花独立叠加。

以总宽 W = 64 为基准：

- 外酥皮：`#C38C55`，描边宽 64。
- 内沿：`#DDB575`，描边宽 52。外酥皮露出每侧 6，即 0.09375 W。
- 内馅：`#F3D994`，描边宽 42。内沿露出每侧 5，即 0.078125 W；内馅宽 0.65625 W。
- 三档烤斑：浅 `#D5AE68`、中 `#CE9C57`、深 `#BE824A`。这是有限固有色变化，不是光照。
- 酥皮细纹：`#A97545`。所有细纹使用同一色。

三层使用同一个中心路径和圆端帽。酥皮厚度、内沿厚度与内馅宽度随 W 等比缩放。圆端是全身真实头尾处的几何端帽，不额外绘制脸部、分节线或假高光。

## 圆弧与接口

推荐中心转弯半径 R = 56，即 0.875 W。检验样张也覆盖 R = 48，即 0.75 W 的紧密 U 弯。必须保持 R > W / 2，避免内侧轮廓塌缩。

每个正交拐点在进入和离开方向各退让 R，以相切的四分之一圆弧相连。圆弧为精确圆，不使用不一致的手绘转角或近似拼块。相邻拐点之间的直线长度必须容纳两侧退让；长度不够时统一调整布局或半径。三层的轮廓沿同一中心圆弧自然形成同心偏移，不能分别绘制三种不同弯道。

可编辑静态几何源：`snake/source/body-geometry-v2.mjs`；同源接口样张与路径数据：`snake/geometry/*-v2.svg`、`*-v2.png`、`geometry-fixtures-v2.json`。包含直段、四种转角和左右圆端，视口均为 192 × 192，接口中心对齐。接口样张用于核对结构，不能作为游戏中的独立分层块反复叠贴，否则会出现内沿覆盖接缝。

## 贴花约束与跟随规则

贴花优先留白：烤斑中心距离约 0.67-0.98 W，长度约 0.19-0.33 W，宽度约 0.13-0.22 W；左右偏移限定为 ±0.12 W，局部旋转限定为 ±0.27 弧度（约 15.5 度）。十二种轮廓选择排除前两枚烤斑的类型。颜色仅在已有三档中变化，不逐帧调色。

酥皮细纹是稀疏的两条短线组，沿路径方向排列，左右交替；中心横向偏移 ±0.451 W，沿身长度约 0.30-0.39 W，总横向宽度 0.07 W，组间距约 2.2-3.3 W。裁切在外酥皮带内，避免进入内馅。它们应能看见，但不抢过烤斑。

图集中的 `frame` 包含透明边距，枢轴在 0.5 / 0.5。实现缩放时使用 `contentBounds` 计算实际图案尺寸，不能把整个 256 像素透明方格当作烤斑实体尺寸。图集每格至少约 50 像素透明边距，禁止有损压缩、描边扩张或白底导出。

运行时应为每个纹理保存持久 id、材料坐标 m、类型、尺寸、偏移和旋转。这里约定 m 是从真实头部向尾部量取的永久材料距离。身体沿路径前进时，根据当前连续中心线在同一 m 上求位置与法线；增长通过增加尾部可见材料范围分配新 id，原有记录保持不变。不能用临时数组序号重新播种，不能每帧重新随机。

转弯时建议将贴花本地顶点 (u, v) 映射为 `P(m + u) + N(m + u) * v`。局部旋转在映射前应用。这样斑点和细纹会随弧线弯曲；单纯把刚性贴花旋转一个角度，只适合很小的斑点。烤斑裁切于内馅，细纹裁切于酥皮带。定稿样张已按此映射导出。

`snake/source/material-layout-v2.json` 保存固定种子 20261016 和预分配的材料记录。`../previews/art-assets/material-state-fixtures-v2.json` 保存移动、增长与穿屏样张的路径、id 和位置，可用于对照实现结果。增长样张中新出现的部分才补纹理，已有记录的类型、m 和位置不变；新增区段以几何裁切逐步显露。

## 屏幕循环

先保留未经屏幕取模的完整连续路径，在需要的方向复制平移一个画面宽或高，最后裁切到视口。贴花与身体一起复制，所有副本复用同一份材料记录。边界仅裁切身体与纹理，不产生新的圆端帽。只有真实头尾拥有端帽。示例 `boundary-wrap-v2.svg` 在宽 600 的视口内用 -600、0、600 平移显示同一路径。

## 重新导出

需要 Node.js 与 sharp。在能解析 sharp 的环境中，从项目根目录运行：

```powershell
node art-tools/export-art-v2.cjs
node art-tools/verify-delivery-v2.cjs
```

导出器读取保留的生成原图、统一几何源和配色，重建同版本资产及样张。修改设计后应先提升输出版本，保留本次交付。项目未添加应用依赖、网页或游戏入口。
