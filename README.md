# 超长蛋挞

支持在线游玩的 2D 贪吃蛇原型：[立即游玩](https://YYlee-orange.github.io/long-egg-tart/)。

本地运行：双击 **启动游戏.cmd**，或在项目目录执行 `node scripts/serve.mjs`，打开 http://127.0.0.1:4173/ 。无需构建或安装依赖，已附运行所需的美术与图标。

## 网页发布

`main` 分支推送后，GitHub Actions 自动检查源码、测试游戏规则并发布 GitHub Pages。可在仓库的 Actions 页面查看发布结果。工作流位于 `.github/workflows/pages.yml`。

`npm run build`（或 `node scripts/build.mjs`）生成可部署的 `dist/`，只包含游戏入口、程序、关卡、实际使用的美术与图标许可。无需服务器后端，资源全部使用相对地址，兼容 GitHub Pages 的仓库子路径。可把 `dist/` 直接交给任意静态网站服务。重新克隆后运行检查与打包不需要安装依赖；重新导出图标时才需要开发依赖。

## 操作

- 点击“开始游戏”按钮开始。方向键或 WASD 转向，移动途中即可输入；禁止直接反向，快速连续转弯支持两次排队。
- 空格或 Esc 暂停／继续；R 重新开始。触屏可以滑动转向。
- 每局默认 60 秒，顶部居中仅显示剩余秒数。暂停与切换标签页时，时间和移动进度一起冻结。
- 最后 10 秒数字变红，10 至 1 每秒触发一次果冻缩放和短促“滴”声；暂停、结束、转场时停止，恢复不会重复提示当前秒。系统开启减少动态效果时保留红色和声音，关闭缩放。
- 吃蛋挞液增长一格。撞到自身、墙壁或倒计时归零时结束，弹窗显示“超长长长蛋挞最终长度”和最终格数（包含初始长度），数字框只显示数字，可回到开始界面或再来一次。暂停和结算使用酥皮边框、小蛇装饰与配套按钮素材。
- 切换标签页会自动暂停。无墙的边界可从另一侧对应位置穿出，方向保持一致。

## 美术与关卡

开始界面和游戏界面的背景为 `picnic-cloth-flat-v1.png`，完整显示花边。食物为用户提供的 `custard-carton-custom-v1.png`，显示框为格宽的 1.12 倍，头部使用 v7 张嘴版和兼容闭嘴版。身体沿统一连续路径分三层绘制，转角为相切圆弧；纹理复用美术线 v5 轮廓与永久材料坐标。头部按交付的枢轴和颈部锚点接入，与身体统一缩放。整个连续身体保留未取模坐标，通过平移副本和视口裁切穿屏。

开始界面有两条分别为 7、5 格的蛇，与局内使用相同的格子、身体宽度、头部比例及移动速度。它们各自沿直线移动，从边界滑出并从另一处随机边界滑入，排除刚离开的那个位置；旧边尾部离开与新边头部进入同时显示，不在画面内部突然重生。入场方向朝地图内，局内仍保持原有对边同位置穿屏规则。开始动画不消耗局内时间；隐藏标签页时冻结，系统开启减少动态效果时显示两条静止的蛇。

默认关卡数据为 `levels/open-table.json`。墙壁是格子坐标数组，缺少墙壁的位置可以穿屏；墙壁与身体占据的格子不会生成食物。附带墙壁示例，可通过 http://127.0.0.1:4173/?level=bakery-walls 打开。原型界面仍只有开始界面和游戏界面。

当前地图为 20 × 11 格，让蛇头、身体和食物在画面中约为初版的 1.5 倍以上，同时保留原有酥皮厚度和圆弧比例。网页外围为纯暖灰色，地图四周保留留白，背景图片范围就是实际游戏边界。

移动与碰撞每 165 毫秒结算一格，显示则在每个浏览器动画帧更新。头尾沿同一条连续圆弧路径插值，增长时尾端保持位置，纹理使用稳定材料坐标；穿屏保留完整路径再复制裁切。暂停会冻结当前运动进度，恢复后从原位置继续。背景和墙壁预先缓存，避免逐帧重复缩放静态背景。

方向输入随时接收并缓存，在前方最近的合法节点执行；已经离开的节点不能再改写。只有仍停在节点上时可以直接选择这一节点的出口，移动途中输入则留给下一节点，不重置计时。蛇头旋转中心在每步起止时与对应格子中心一致，颈部通过短相切直线连接原有圆弧，不再用整条路径变形来追溯转向。网格判定与原有吃食物、增长、碰撞和穿屏机制保持一致。

开始、重开与返回使用八条长蛋挞错时横滑转场，每条沿用蛇身的酥皮、蛋液和碎斑纹理，两端均为圆形收口，不带头部。遮罩完全覆盖后切换画面，转场不消耗局内时间。暂停和结束使用居中弹窗，后方游戏画面与顶部控件明显模糊；弹窗提供文字按钮。支持系统减少动态效果设置。

倒计时时长由关卡 JSON 的 `roundSeconds` 配置，当前两个关卡均为 60 秒。`src/countdown.js` 独立管理剩余时间，按真实经过的毫秒扣减、向上取整显示秒数，运动预测与提交不会回滚计时。每次重开重新创建计时器。

角色保持固有色平涂，未烘焙阴影或添加场景光照。食物使用用户新提供的透明蛋挞液素材。

## 开发

运行 `node --test tests/*.test.mjs` 检查规则与几何；`node scripts/check.mjs` 检查源码语法和素材路径。浏览器检查脚本位于 `scripts/browser-check.cjs`，需要 Playwright。Phosphor 图标已随项目保存，授权见 `assets/ui/PHOSPHOR-LICENSE.txt`；只有重新导出图标时需要安装开发依赖。
